# TaigiKeyboard Homebrew Tap

Homebrew cask for [TaigiKeyboard](https://github.com/taigikeyboard/taigikeyboard), a Taiwanese input method (POJ / TL / TPS, Hanji) for macOS.

## Install

```sh
brew install --cask taigikeyboard/tap/taigikeyboard
```

Then add **TaigiKeyboard** in System Settings → Keyboard → Text Input → Edit…. Requires macOS 14 (Sonoma) or later.

## Uninstall

```sh
brew uninstall --cask taigikeyboard
```

## Version

The cask version tracks the latest published macOS release on the [releases page](https://github.com/taigikeyboard/taigikeyboard/releases). The app also checks for updates on its own.
